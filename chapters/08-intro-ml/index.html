Введение в машинное обучение

Как научить компьютер учиться на данных — без явного программирования

Новая парадигма

Традиционное программирование: вы пишете правила. Машинное обучение: вы даёте данные и ответы — компьютер сам находит правила.

Линейная регрессия

Простейший ML: найти прямую, которая лучше всего проходит через точки данных. Прямая «подстраивается» под данные.

Функция потерь

MSE = $\frac{1}{n}\sum(y_i - \hat{y}_i)^2$ — мера ошибки. Чем меньше — тем лучше модель описывает данные. Обучение = минимизация потерь.

Классификация

Не только числа: ML может предсказывать классы. Логистическая регрессия, SVM, деревья решений, нейросети — все решают задачу классификации.

Математика ML

Линейная модель предсказывает значение как линейную функцию признака:

$$\hat{y} = wx + b$$

Функция потерь MSE (среднеквадратичная ошибка) измеряет качество модели:

Функция потерь $$\text{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$

Оптимальные параметры $w$ и $b$ минимизируют MSE. Для линейной регрессии есть аналитическое решение:

$$w = \frac{\sum(x_i - \bar{x})(y_i - \bar{y})}{\sum(x_i - \bar{x})^2}, \quad b = \bar{y} - w\bar{x}$$

Интересный факт

Метод наименьших квадратов изобрели Лежандр и Гаусс более 200 лет назад. Тот же принцип лежит в основе современных нейросетей — только вместо прямой подбирается сложная нелинейная функция.

Для классификации используется логистическая (сигмоидная) функция, которая «сжимает» выход в диапазон [0, 1]:

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

Границы классификации

ЛКМ — класс 1 (синий), ПКМ — класс 2 (оранжевый). Разделяющая линия обновляется автоматически
